# HiRouter

**VPN для всей домашней сети, управляемый прямо из веб-интерфейса роутера.**

HiRouter — надстройка над OpenWrt: она добавляет в веб-интерфейс роутера вкладку «HiRouter»,
через которую включается защищённое подключение сразу для всех устройств в сети — компьютеров,
телефонов, телевизоров, приставок. Приложения на устройствах не нужны: они просто подключаются
к своему Wi-Fi и получают уже отфильтрованный трафик.

Система состоит из двух пакетов: **движок** на ядре mihomo — то, что реально гоняет трафик, —
и **агент HiRouter**: страница управления, локальный API и связь с панелью администратора. Оба ставятся одной командой, дальше роутер обслуживает себя сам.

```sh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/alex-dde/hirouter/main/dl/install.sh)"
```

Текущая версия агента — **0.3.19**.

## Возможности

**Для всей сети сразу.** Один раз настроили роутер — защищены все устройства, включая те, куда
VPN-клиент не поставить: телевизоры, консоли, умные колонки, камеры.

**Три режима маршрутизации.** «Умный» (российские сайты напрямую, остальное через VPN), «весь
трафик через VPN» и «напрямую». Переключаются одним кликом, без консоли и конфигов.

**Точечные правила по доменам.** Отдельный сайт можно принудительно пустить через VPN, оставить
напрямую или заблокировать — маской (`*.example.com`) или подсетью (`1.2.3.0/24`).

**Свои VPN-ключи.** К серверам, выданным по подписке, владелец добавляет собственные: поддерживаются
`vless://`, `hysteria2://`, `trojan://`, `ss://`, `vmess://`. Ключи можно проверять пингом прямо
из интерфейса.

**«VPN по кнопке».** Отдельный пул серверов, на который весь трафик переключается одним тумблером —
а на Cudy TR3000 и Huasifey WR3000H Pro ещё и физической кнопкой на корпусе.

**Честный статус вместо тишины.** Если рабочих серверов не осталось, система не делает вид, что
VPN работает: она возвращается в прямой режим и прямо об этом сообщает. Трафик не уходит «вникуда».

**Безопасное самообновление по воздуху.** Пакет скачивается, сверяется по sha256 и ставится под
сторожевым таймером: если новая версия не поднялась, роутер автоматически откатывается на прежнюю.
Сорвавшаяся установка не блокирует роутер — флаг «идёт установка» протухает за 15 минут.

**Контроль подписки и трафика.** На странице видны срок действия, тариф и израсходованный трафик.
Когда подписка заканчивается, обычный интернет продолжает работать, а клиенту показывается
уведомление о том, что VPN отключён.

**Диагностика на месте.** Задержки до панели, до VPN-сервера и до контрольных сайтов измеряются
прямо с роутера и видны и владельцу, и администратору. Определяются тип аплинка (кабель или
сотовый модем), оператор и уровень сигнала, а также ситуация «оператор пускает только белый
список сайтов».

**Восстановление DNS.** Если ядро VPN подвисает и перехваченный DNS перестаёт отвечать, агент
чинит резолвинг самостоятельно, не дожидаясь вмешательства.

## Поддерживаемое оборудование

| Требование | Значение |
|---|---|
| Прошивка | OpenWrt с пакетным менеджером `opkg` и веб-интерфейсом LuCI |
| Архитектура | `aarch64_cortex-a53` |
| Проверено на | Cudy TR3000, Huasifey WR3000H Pro |

Установщик сам определяет архитектуру роутера. Если готового пакета для неё нет, он честно об этом
скажет и ничего трогать не станет — так что запуск на неподдерживаемом устройстве безопасен.
Сборка под другую архитектуру возможна: сообщите модель роутера.

---

## Требования

- Доступ к роутеру по SSH под `root` (или окно «Терминал» в веб-интерфейсе, если прошивка его даёт).
- Работающий интернет на роутере — установщик скачивает около **17 МБ**.
- Свободное место в `/opt`: ядру mihomo нужно примерно **35 МБ** после распаковки. На устройствах
  с 8 МБ флеша без внешнего накопителя система не поместится.
- Пакеты `curl` и `ca-bundle`. Обычно уже есть; если нет —
  `opkg update && opkg install curl ca-bundle luci-compat`.

## Установка

Подключитесь к роутеру по SSH и выполните:

```sh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/alex-dde/hirouter/main/dl/install.sh)"
```

Если на роутере нет `curl`, но есть `wget`:

```sh
wget -qO- https://raw.githubusercontent.com/alex-dde/hirouter/main/dl/install.sh | sh
```

Установка занимает 2–4 минуты, из них около минуты — ожидание первого ответа панели. **Не
перезагружайте роутер в процессе.**

По окончании установщик печатает сводку:

```
──────────────────────────────────────────────
 HiRouter установлен
 серийный номер : RRa83878135f2aad
 версия агента  : 0.3.19
 VPN запущен    : да
 серверов       : 7
──────────────────────────────────────────────
```

**Серийный номер сообщите администратору** — по нему роутер подтверждают в панели и выдают
подписку. До подтверждения строка «серверов» будет `0`, и это нормально: конфигурация приедет
сама в течение пяти минут после одобрения.

### Установка без доступа в интернет с роутера

Скачайте на компьютер файлы `dl/hirouter-core.ipk` и `dl/hirouter.ipk` (или пакеты из нужного
[релиза](https://github.com/alex-dde/hirouter/releases)), скопируйте их на роутер и поставьте
вручную:

```sh
scp dl/*.ipk root@192.168.10.1:/tmp/
ssh root@192.168.10.1
opkg install /tmp/hirouter-core.ipk
opkg install /tmp/hirouter.ipk
```

Порядок важен: сначала движок, потом агент.

## Что делает установщик

Скрипт написан так, чтобы ничего не ломать до того, как убедится, что замена скачана целиком.

1. **Определяет архитектуру** роутера (`opkg print-architecture`, запасной путь — `/etc/openwrt_release`).
2. **Читает `manifest.txt`** — список пакетов и их контрольных сумм для этой архитектуры. Версии
   в сам скрипт не зашиты, поэтому новый релиз не требует его правки.
3. **Скачивает оба пакета и сверяет sha256.** Если сумма не сошлась — установка отменяется, роутер
   остаётся нетронутым.
4. **Снимает прежнюю установку**: останавливает службы, удаляет прежние пакеты агента и движка,
   вычищает каталог с их старой конфигурацией и сбрасывает `/etc/hirouter/state.json` — иначе
   агент решит, что менять нечего, и оставит роутер без конфигурации.
5. **Ставит движок, затем агента.**
6. **Запрашивает первый синк** с панелью и печатает итоговое состояние.

Источники скачивания перебираются по очереди: сначала GitHub, затем `up.hirouter.info`. Недоступность
одного не останавливает установку.

## Проверка после установки

Откройте в браузере веб-интерфейс роутера и перейдите на вкладку **HiRouter**. Либо проверьте
из консоли:

```sh
# служба поднята
/etc/init.d/hirouter status

# что видит сам агент
curl -s -H "X-Local-Token: $(cat /etc/hirouter/local.token)" http://127.0.0.1:9001/status

# что установлено
opkg list-installed | grep hirouter
```

В ответе `/status` смотрите на три поля: `version` (должна совпадать с установленной),
`clash_running` (`true`) и `proxies` (число серверов; `0` до подтверждения роутера в панели).

## Как это устроено

```
┌─────────────────────────────────────────────┐
│  Роутер (OpenWrt)                           │
│                                             │
│   вкладка HiRouter в LuCI                   │
│            │                                │
│            ▼                                │
│   агент HiRouter  ──── локальный API :9001  │
│            │                                │
│            ▼                                │
│   движок (ядро mihomo)                      │
│            │                                │
└────────────┼────────────────────────────────┘
             │  весь трафик домашней сети
             ▼
      VPN-серверы  /  прямой выход
```

**Агент** — небольшая служба на роутере. Она рисует страницу управления, держит локальный API
для интерфейса и раз в пять минут выходит на связь с панелью администратора: забирает
конфигурацию, состояние подписки и список серверов, отправляет телеметрию.

**Связь всегда инициирует роутер.** Он стоит за NAT провайдера, снаружи к нему не подключиться,
поэтому всё, что администратор меняет в панели, доезжает не мгновенно, а на ближайшем выходе
роутера на связь — не дольше пяти минут. Кнопка «🔄 Обновить CFG» на странице роутера запрашивает
синхронизацию немедленно.

**Экранов управления три,** и это разные вещи:

| Экран | Адрес | Для кого |
|---|---|---|
| Страница HiRouter | `http://<роутер>/cgi-bin/luci/admin/hirouter` | владелец роутера, основной экран |
| Дашборд подключений | `http://<роутер>:9003` | владелец: какие серверы выбраны, что и куда сейчас ходит |
| Служебный дашборд | `http://<роутер>:9002` | администратор, под токеном |

Все три доступны только из домашней сети роутера.

## Режимы маршрутизации

| Режим | Что делает | Когда выбирать |
|---|---|---|
| **Smart Routing** | Российские сайты идут напрямую, остальное — через VPN | Повседневный режим: местные сервисы быстрые, трафик подписки не тратится |
| **Global VPN** | Весь трафик без исключений уходит в туннель | Когда нужно, чтобы ни один сайт не видел настоящий IP |
| **Direct** | VPN выключен, весь трафик напрямую | Банк, госуслуги и прочее, что не любит «иностранные» адреса |

Режим переключается кликом по карточке, код доступа не нужен. Smart Routing и Global VPN работают
на общем пуле серверов — какие источники в нём участвуют, задаётся тумблерами отдельно.

---

## Источники VPN-серверов

- **VPN из подписки** — серверы, выданные администратором. Их адреса владельцу не показываются:
  на странице только счётчик, чтобы конфигурацию нельзя было переписать с экрана. Отдельные
  серверы могут быть подписаны по решению администратора.
- **Пользовательские VPN** — собственные ключи владельца, добавляются вставкой ссылки.
- **Публичные списки** — бесплатные серверы из списков, заданных администратором. На базовом
  тарифе включаются автоматически, чтобы роутер не остался вовсе без выхода.
- **VPN по кнопке** — отдельный пул со своим тумблером: когда он включён, весь трафик идёт строго
  через него. Не включается с пустым списком.

Система не даст удалить или выключить последний работающий сервер, если VPN держится только на нём.

## Обновление

**Обычный путь — по воздуху.** Когда выходит новая версия, на странице роутера появляется блок
с кнопкой «⬆️ Обновить». Нажатие скачивает пакет, сверяет контрольную сумму и ставит его под
сторожевым таймером; если версия не поднялась — откат на прежнюю происходит автоматически. VPN
прерывается примерно на 30 секунд, роутер перезагружать не нужно.

**Повторная установка поверх.** Та же команда, что и при первой установке, ставит текущую версию
из манифеста начисто, со сбросом прежней конфигурации. Это способ вылечить роутер, у которого
конфигурация пришла в негодность.

```sh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/alex-dde/hirouter/main/dl/install.sh)"
```

Пользовательские настройки — свои ключи, домены, выбранный режим — хранятся в панели и приезжают
обратно на первом синке.

## Удаление

```sh
/etc/init.d/hirouter stop
/etc/init.d/clash stop
opkg remove hirouter
opkg remove luci-app-ssclash
rm -r -f /opt/clash /etc/hirouter
```

После этого роутер работает как обычный OpenWrt: весь трафик идёт напрямую.

## Диагностика

**Установщик не смог скачать манифест.** На роутере нет DNS или закрыт исходящий трафик. Проверьте:

```sh
ping -c2 1.1.1.1                     # есть ли сеть вообще
nslookup raw.githubusercontent.com   # работает ли DNS
```

**«для архитектуры … пакета нет».** Устройство не из поддерживаемых. Сообщите модель роутера и
вывод `opkg print-architecture` — под неё можно собрать пакет.

**«не установился движок».** Чаще всего не хватает места на флеше. Проверьте `df -h` — в разделе
с `/opt` нужно около 35 МБ свободных.

**«не установился агент».** Не хватает зависимостей:

```sh
opkg update && opkg install curl ca-bundle luci-compat
```

**Статус «нет VPN» на странице.** Движок работает, но рабочих серверов нет. Нажмите 🔄 в карточке
«VPN серверы», проверьте, включён ли нужный источник, и нажмите «🔄 Обновить CFG».

**Серверов 0 и не появляются.** Роутер ещё не подтверждён в панели. Сообщите администратору
серийный номер — он показан в шапке страницы и копируется кнопкой 📋.

**Интернет пропал совсем.** Выключите главный тумблер в шапке страницы — вся VPN-обвязка отходит
в сторону, трафик идёт напрямую. Если интернет вернулся, дело в конфигурации VPN.

**Роутер заблокирован администратором.** Локально такую блокировку снять нельзя — обратитесь
к администратору, назвав серийный номер.

Подробный разбор интерфейса и частых сценариев — в [руководстве владельца](docs/user-guide.md).

## Состав репозитория

```
dl/
  install.sh              установщик, запускается на роутере
  manifest.txt            какие пакеты и с какими sha256 ставить, по архитектурам
  hirouter-core.ipk       движок HiRouter: ядро mihomo
  hirouter.ipk            агент HiRouter: страница, локальный API, связь с панелью
docs/
  user-guide.md           руководство владельца роутера
CHANGELOG.md              что менялось в каждой версии агента
```

**Имена пакетов не содержат версию намеренно** — ссылка на файл одна и та же во всех
инструкциях и не устаревает при выпуске новой версии. Какая версия лежит в `dl/` прямо
сейчас, написано в `manifest.txt` и в первой записи `CHANGELOG.md`. Версия, зашитая в сам
пакет, видна после установки в `opkg list-installed` и в ответе `/status`.

Конкретные версии остаются доступными в [релизах](https://github.com/alex-dde/hirouter/releases):
там пакет выложен под именем с номером версии, и оттуда можно поставить или откатить нужную.

Ядро mihomo лежит **внутри** пакета движка — отдельно оно не качается и во время работы
ничего из интернета не подтягивает.

## Выпуск новой версии

Сам `install.sh` при релизе править не нужно — он читает всё из манифеста.

1. Положить новый пакет в `dl/hirouter.ipk` (**поверх прежнего, имя не меняется**).
2. Посчитать сумму: `shasum -a 256 dl/hirouter.ipk`.
3. В `dl/manifest.txt` обновить в строке нужной архитектуры сумму агента и номер версии.
4. Добавить запись в `CHANGELOG.md`.
5. Закоммитить и запушить.
6. Выпустить релиз: тег `v<версия>`, в описание — запись из `CHANGELOG.md`, вложением
   приложить пакет под именем с версией (`hirouter_<версия>.ipk`), чтобы конкретный выпуск
   можно было скачать и позже.

```sh
gh release create v0.3.20 \
  --title "HiRouter 0.3.20" \
  --notes-file notes.md \
  dl/hirouter.ipk#hirouter_0.3.20.ipk
```

Формат строки манифеста:

```
архитектура|файл движка|sha256|файл агента|sha256|версия агента
```

Строки, начинающиеся с `#`, — комментарии. Для каждой поддерживаемой архитектуры своя строка.
Движок `hirouter-core.ipk` меняется редко и описывается в той же строке манифеста.
